## Formatos

este septiembre 2026 estamos haciendo revisiones de las placas y de formatos, hice estos apuntes:

### principales

nombre: parla línea
formato: standalone
interfaz: 2x potes
entradas: 1x TRS 1/8"
salidas: 1x parlante, 1x TRS 1/8"

nombre: parla línea extensor
formato: standalone
interfaz: nada
entradas: 1x TRS 1/8"
salidas: 1x parlante

nombre: parla eurorack
formato: eurorack
interfaz:  2x potes
entradas: 1x TS 1/8"
salidas: 1x parlante, 1x TS 1/8"

nombre: parla eurorack extensor
formato: eurorack
interfaz:
entradas: 1x TS 1/8"
salidas: 1x parlante

### otros

nombre: parla guitarra
formato: standalone
interfaz:  1x pote
entradas: 1x TS 1/4"
salidas: 1x parlante

nombre: parla estéreo
formato: standalone
interfaz: 2x potes
entradas: 1x TRS 1/8"
salidas: 2x parlantes
